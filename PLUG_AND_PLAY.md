# PLUG_AND_PLAY — zeroclaw-arena

> *Integration guide.*


## Feature Flags

| Feature | Default | Description |
|---------|---------|-------------|
| `std` | yes | Standard library |
| `alloc` | yes | Allocator support |

## Integration

Import `zeroclaw_arena` in your project to access the functionality.

```
use zeroclaw_arena::{};
```

## Compatibility

- **Rust edition**: 2021+
- **Targets**: All tier-1 Rust targets
