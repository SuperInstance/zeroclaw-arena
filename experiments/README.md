# Experiments

Research scripts from the ZeroClaw exploration phase. Each script is a self-contained experiment.

## Key Experiments

| File | Description |
|------|-------------|
| `tile_compiler.py` | Original tile compiler (integrated into `zeroclaw.compiled_policy`) |
| `evolutionary_strategy.py` | Evolution-based strategy discovery |
| `holdem_tile.py` | Texas Hold'em tile field learning |
| `penrose_tile.py` | Penrose tiling applied to game states |
| `entropy_production.py` | Entropy-based exploration |
| `hierarchical_tiles.py` | Multi-resolution tile hierarchies |
| `gpu_tile_factory.py` | GPU-accelerated tile operations |
| `streaming_tile_svd.py` | Streaming SVD for tile compression |

Results are in `../results/`.
